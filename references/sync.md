# Selected synchronization and manual updates

## Selected-item synchronization

Process only requested items/courses and necessary related records. Read the entire [sync policy](sync-policy.md) before Events/Courses/Study Pattern synchronization. Inspect current schema, source evidence and existing Notion records before writing; deduplicate conservatively and preserve manual progress, notes and source history.

Full-source collection, dashboard description updates and per-run reporting in the shared policy belong to full Daily Brief runs. A selected sync does not run full Daily Brief, update the dashboard's last-updated description unless explicitly requested, or use the full brief format. Report created/updated/unchanged counts, Notion links and material gaps. Read back failed or uncertain writes before retrying.

## Explicit manual progress edits

Locate the unique target and change only the status/notes the user requested. Read relevant locations/schema in the sync policy and inspect the target first. Preservation rules do not prevent the user from changing their own state. Ask only when multiple candidates cannot be distinguished. Do not collect all sources or alter unrelated records.
