# Full Daily Brief mode

Run only for an explicit full brief/full sync or the existing PolyU Daily Brief schedule. Existing scheduled authorization covers its Notion updates without reconfirmation. An ordinary query, contact lookup, lecture explanation or selected sync does not invoke this mode.

1. Read the entire [sync policy](sync-policy.md) and [Daily Brief output](daily-brief-output.md).
2. Search the past 24 hours of Gmail and obtain a fresh 21-day LMS overview using the shared source and authentication rules.
3. Synchronize Events/Courses/Study Pattern with original evidence, deduplication and preservation rules; update the Events dashboard description as specified in the policy.
4. Return the full brief in the required format. Report unavailable sources as gaps, continue successful sources, and do not wait indefinitely for unattended authentication.

Keep detailed policy and output requirements in those shared files so scheduled and manual briefs use the same rules.
