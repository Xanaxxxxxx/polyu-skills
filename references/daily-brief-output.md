# Daily Brief output

Produce the brief in Traditional Chinese. The Chinese labels below are intentional output literals, not untranslated instructions.

Title: `PolyU Daily Brief — YYYY-MM-DD`

1. `一句話結論` — one-sentence conclusion.
2. `Notion Calendar / Actions` — table with columns Day | Time | Event | Type | My State | Source | Notion.
3. `需要補資料` — item name; missing dates/time/venue/actions, official course name, credits, component, semester, requirement, or LMS authorization/platform failures; source unit/short subject/platform with Source and Notion links.
4. `需要確認更新` — existing event, old time → new time, reason, and source/Notion links. This is a report section, not an extra approval gate for already-authorized updates.
5. `值得知道` — FYIs not included in the Notion actions table: name, one-sentence relevance assessment, time if known, and Gmail/Canvas/Blackboard source link.
6. `可忽略` — one sentence grouping ignored messages/announcements; do not list each separately.
7. `處理狀態`:
   - Gmail: not marked read; no replies.
   - LMS: successful Canvas/Blackboard sources plus authorization/coverage gaps.
   - Notion: created/updated counts for Events, Courses, and Study Pattern; actual outcome of Events description update; views untouched.
   - Google Calendar: unused; no PolyU projections created/updated/deleted.

Report actual results, not assumed success. State uncertainty about dates, venues, deadlines, actions, or judgments explicitly; never guess.
