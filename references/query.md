# Query mode

Answer academic questions with the smallest useful read scope. Do not write Notion, change descriptions/icons, mark messages read, or run Daily Brief.

- **Notion-only requests:** Read relevant databases/pages only. Consult locations/schema in [sync policy](sync-policy.md) as needed; do not scan Gmail/LMS.
- **LMS questions:** Follow the installed lms-cli:lms-query skill, read profiles, and pass canvas-polyu-edu-hk explicitly. Resolve the relevant course and read current course information, announcements, or linked materials. Use bounded overview tools for cross-course schedules/deadlines, then follow relevant gaps rather than crawling every file.
- **Original email evidence:** Use Gmail only when the question needs email notices, recruitment, competitions or related source evidence; do not mark read or reply.
- If the source is not specified, choose the source needed to answer: Notion for recorded personal state/progress, LMS for current teaching information, original email for email notices. Check conflicting dates against original evidence and preserve uncertainty. Events.Date is canonical structured state under the sync policy; a discrepancy can be reported without silently editing it.
- Lead with the answer, cite source links, and disclose stale records, missing authentication, partial coverage or ambiguous applicability. An unavailable source is not an empty result.

For lecturer contact questions, return to [contacts](contacts.md) after identifying the current instructor. A request to save/update results moves only the requested scope to [sync](sync.md).
